# Measurement Protocol

For each of the six indicators, document:
1. Concept and purpose
2. Exact operational definition
3. Formula
4. Unit and frequency
5. Nominal/real treatment
6. Stock/flow classification
7. Preferred source and alternative sources
8. Publication lag and revision policy
9. Historical availability and comparability
10. Interpretation cautions
11. Example calculation
12. Status and next action

Complete and review each specification before using it for formal state classification.
