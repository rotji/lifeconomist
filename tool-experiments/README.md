# Tool Experiments

The aim is to learn which tools support the actual research workflow.

## Experiments
- VS Code vs Obsidian for editing and linking Markdown.
- GitHub commits for preserving document and decision history.
- Zotero for collecting and citing source literature.
- LibreOffice Calc vs Google Sheets on the same small indicator dataset.
- ChatGPT plus saved records for continuity across sessions.

## Evaluation criteria
Score from 1 (poor) to 5 (excellent), and add notes:
- Ease of use
- Reliability
- Cost
- Offline access
- Portability/export
- Version history
- Search and retrieval
- Collaboration
- Fit with the research method
- Time saved

## Rule
Do not maintain duplicate authoritative copies indefinitely. During experiments, label test copies and the authoritative version. Choose based on observed use, not assumptions.
